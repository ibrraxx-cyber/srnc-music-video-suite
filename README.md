# SRNC Music Video Suite

Professional music-video toolkit for Adobe Premiere Pro and After Effects.

## v0.1
- Premiere Pro UXP panel starter
- Dark SRNC production UI
- Effects / Motion / Transitions / Presets / Sauce sections
- ONE CLIP and TWO CLIPS transition separation
- Shared editable preset catalog
- Drill, Trap, Dark, Cinematic, Street, Hype and Sauce categories

## Structure
- `apps/premiere-uxp` — Premiere Pro UXP panel
- `apps/after-effects` — After Effects host adapter starter
- `packages/core` — shared preset schema and validation

## Premiere target
Premiere Pro 25.6+ with UXP Developer Tool.

## Status
This is the foundation release. The UI is functional as a panel prototype; host-side APPLY execution is the next integration milestone.
